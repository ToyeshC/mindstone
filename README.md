# Teaching AI Who You Are

Live at: **https://toyeshc.github.io/mindstone/**

Static companion website for the talk given at Mindstone Amsterdam on May 20, 2026.

## What the Site Contains

- A general track for people using ChatGPT or Claude as thinking tools
- A developer track for people building workflows around Claude Code
- An interactive four-layer system covering identity, memory, tools, and constraints
- Identity-file prompts, session openers, and a lightweight developer setup
